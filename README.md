# Auto Meknès Ismailia — Showroom & Digital Hub

Official showroom landing page and digital hub for **Auto Meknès Ismailia** — Concessionnaire Agréé Toyota à Meknès.

## 🚗 Features
- **High-End Luxury Dark Design**: Minimalist, high-performance automotive UI.
- **Bilingual (FR / AR)**: Seamless instant language switcher with full RTL/LTR support.
- **Vehicle Showcases**: Land Cruiser Prado, Corolla Berline Hybride, Corolla Cross AWD Hybride.
- **Interactive Modals**:
  - Test Drive Booking (*Réserver un Essai* / *طلب تجربة قيادة*) with WhatsApp integration.
  - Interactive Vehicle Comparator (*Comparateur* / *المقارن*).
  - Technical Specs (*Fiche Technique* / *المواصفات التقنية*).
  - Dedicated Sales Advisors (*Notre Équipe* / *فريق المبيعات*).
  - Trade-In Valuation (*Reprise Auto* / *استبدال سيارتك*).
- **Mobile-First & Touch-Optimized**: Responsive bottom sheet modals, sticky bottom quick bar, safe-area-inset support.

## 🌐 Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Montserrat & Cairo)
